# COOK · 私厨

> 说一声，厨房有人接。一个把「想吃什么」变成「全家一起吃」的家庭餐桌应用。

- **产品**: 家庭点单 / 接手 / 评分 / 收藏 / 心愿 / 成就 / 家庭广场 / AI 推荐
- **架构**: Vite + React (PWA) 前端 / Hono + SQLite + Drizzle 后端 / 阿里云百炼 qwen-turbo / Tencent COS 图片
- **产品文档**: 见 [`private-chef/`](./private-chef/)
- **功能总览页**: `https://weilanshanshan.top/showcase.html`
